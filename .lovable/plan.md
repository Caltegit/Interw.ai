# Redonner accès aux images « fond tableau peinture » de la landing

## Objectif

Les trois fonds peints utilisés sur la landing existent déjà dans le projet (`src/assets/backgrounds/`), mais ne sont pas accessibles directement depuis vos fichiers. Les copier dans vos documents pour que vous puissiez les ouvrir et les télécharger.

## Ce qui est prévu

Copier, sans aucune modification, les trois images existantes :

- `painting-bay.jpeg`
- `painting-pier.jpeg`
- `painting-shore.jpeg`

vers le dossier `fonds-landing/` de vos fichiers, puis les afficher dans le chat.

Aucun changement sur la landing ni sur aucun fichier du projet.
